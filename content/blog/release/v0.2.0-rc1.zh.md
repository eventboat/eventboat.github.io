我们很高兴宣布 **v0.2.0-rc1**——Eventboat（Agent 原生事件路由器）的首个候选发布版本。

## 包含什么

- **Agent 原生**：MCP 服务器 15 个工具覆盖完整生命周期
  （catalog → verify → test → explain → deploy → status → trigger → tail → 死信回放）
- **零自研语言**：CEL 谓词（K8s 标准）+ Starlark 转换（Python 方言、沙箱、确定性）
- **可靠性引擎**：spool + settle + checkpoint（SQLite），七条不变量测试，
  kill -9 从水位恢复，死信库可查可回放
- **作业管道**：cron 调度、补偿窗口、重叠策略、类型化参数（回补）
- **扩展阶梯**：CEL → Starlark → WASM（wazero）→ gRPC 进程外插件
- **CESQL 方言**：CloudEvents 互操作（可选），官方 TCK 100%
- **LSP**：编辑器诊断、补全、hover
- **CLI**：11 个命令，基于 [lynx-go/commands](https://github.com/lynx-go/commands)，
  `--json` 输出面向 Agent 和 CI

## 快速上手

```bash
go install github.com/eventboat/eventboat/cmd/eventboat@v0.2.0-rc1
eventboat help
```
